# Supplemental upstream license texts

`packages.json` supplies notices for pinned crates whose registry archives lack a standalone license file. When a mapped crate is upgraded, verify the upstream notice at the new release and update the mapping. These files retain their upstream terms.

- [alloc-stdlib BSD license](https://github.com/dropbox/rust-alloc-no-stdlib/blob/0a81fd6928ea3b33c8cd484aa4575d50ffb98012/LICENSE)
- [dlopen2 MIT license](https://github.com/OpenByteDev/dlopen2/blob/cc80e4a0a90d499b677fdf7743699b4b3a43a989/LICENSE)
- [libappindicator workspace MIT license](https://github.com/tauri-apps/libappindicator-rs/blob/eafd1e3682a1247f595410266091e9684021cb6f/LICENSE-MIT)
- [Mozilla Public License 2.0](https://www.mozilla.org/MPL/2.0/) as included with `cssparser` 0.37.0
- [objc2 workspace licensing](https://github.com/madsmtm/objc2/blob/7b1abfd750a2cacaea71d6a56ecfb83cb7de560b/LICENSE.md) and the [upstream MIT text](https://github.com/madsmtm/objc2/blob/ee9a7ada2131f5944b8750428e265c15632f2a19/LICENSE-MIT.txt)
- [webview2-rs workspace MIT license](https://github.com/wravery/webview2-rs/blob/edc2caf886175ccaebe86078c9cfe1ae2a187328/LICENSE)
